## Selected Projects

### Numerical Analysis of PageRank

A numerical study of the PageRank algorithm, focusing on sparse and matrix-free computation, convergence of the power method, and the effect of the damping factor.

The method was applied to the HEP-TH citation network to compare PageRank with citation-based rankings.

📁 [Project repository](https://github.com/RiccardoInfascelli/numerical-analysis-pagerank)

### Parallel Navier–Stokes Solver

Parallel 3D incompressible Navier–Stokes solver developed in C++ using finite differences, MPI pencil decomposition, FFTW, and 2Decomp.

The project includes numerical validation, profiling, memory/cache analysis, and strong-scaling experiments.

📁 [Project repository](https://github.com/RiccardoInfascelli/parallel-navier-stokes-solver)

### Fluid–Structure Interaction Solver

Monolithic finite-element solver for steady fluid–structure interaction problems in C++, using deal.II, MPI, PETSc, and Trilinos.

The project explores block systems, interface coupling, adaptive refinement, preconditioning, validation, and parallel scalability.

📁 [Project repository](https://github.com/RiccardoInfascelli/fluid-structure-interaction-solver)

### Deep Learning for Computer Vision

Image classification and semantic segmentation projects developed using Python and Keras, exploring transfer learning, fine-tuning, U-Net architectures, data augmentation, and model ensembling.

📁 [Project repository](https://github.com/RiccardoInfascelli/artificial-neural-networks-deep-learning)
